# 模板不是执行结果

所有模板需要Jinlong从实际workflow记录填写/导出。请勿将模板状态写成已完成。当前研究无新增先导步骤；正式参考和联合目录分别冻结。

先按[代码、参数与结果归档规范](../代码参数与结果归档规范.md)选择所需记录。主要模板为ACTUAL_WORKFLOW、actual_parameters、run_records、software_database、figure_provenance和large_file_index；其余模板用于状态、纳排、变更与结果索引。可使用现有workflow的等价导出，无需另外维护一套重复表格。

正式患者、参考、目录及冻结记录使用[04_deliverables中的模板](../../04_deliverables/交付清单与表字段.md)。方法选择填写[决策TSV](../Jinlong_方法与参数决策表.tsv)，实际运行值由配置与命令导出；两者不要混填。
