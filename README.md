# CRC-PHIRE：正式研究交接

**Colorectal Cancer Prophage–Host Interactions and Repertoire Exploration**

本项目共纳入9个CRC病例—合格对照粪便宏基因组队列，分为7个开发队列与2个独立验证队列。两部分均包含CRC病例和各自的研究对照。研究寻找可重复的prophage信号，结合细菌参考基因组解释宿主、整合结构与功能，最后选择1–2个可实验对象。

当前已完成研究设计、公共参考元数据预选和已有结果交接。**Jinlong直接开展正式研究，不另做先导。** 新增参考的序列QC、九队列正式患者分析及联合分析尚未完成；已有10人pilot用于了解方法与经验，是否复用其输入、结果或代码由Jinlong决定。

## 当前已有的材料

- 公共检索返回21,608条组装记录，整理为15,064个元数据身份组；预选1,931份组装，覆盖36个检索单元，按NCBI当前标签分为54个具名种标签及22份未定种记录。这是可下载、待统一QC的候选，最终genome、菌株和物种数量仍需序列及身份核查。
- 已有Feng队列5例CRC＋5名研究对照pilot：参考端541个、患者端382个预测provirus实例，473个定量vOTU，有G—M序列连接和2个复制活动候选。小样本关联未通过全局FDR。方法、结果图、底表与代码见Sendi试跑报告。
- 方法决策和实际运行模板已经备好；待决定项与未运行值保持原状态，不能当作Jinlong已执行的结果。

## 分工与研究顺序

Sendi在Part 0整理设计、文献、候选元数据清单及试跑证据。Jinlong在Part 1并行开展参考FASTA下载/QC/调用和九队列临床身份核对及患者上游；Sendi负责科学范围、临床原则和实验资源。常规工具、数据库、参数与资源调度由Jinlong按成熟流程选择并记录。

患者纳排与开发/保留角色在相应上游前冻结。联合分析前，**先冻结正式细菌参考accession版本及数量，再冻结由参考G与开发患者M构成的联合病毒目录**；随后进入Part 2统一定量、开发关联、宿主与功能解释、复制活动分析及保留队列验证。参考与患者上游可并行，保留队列不参与开发目录构建或候选选择。

## 目录和文件范围

`00_project`保存计划与执行说明；`01_reference`、`02_cohorts`保存输入来源和清单；`03_execution`保存方法选择、归档规范与模板；`04_deliverables`定义正式交付和冻结；`05_existing_results`保存已有结果证据；`06_literature`保存文献依据；`90_package`保存公开文件索引及校验记录。

公开包提供代码、配置模板、公共来源清单、关键表图与图源数据。参考FASTA、患者FASTQ/组装/BAM、数据库与大缓存按清单在相应数据区获取或保存；服务器连接、凭据和内部路径通过私下安全渠道交接。公开方法副本使用逻辑路径，文件完整性按[公开文件manifest](90_package/public_file_manifest.tsv)核对。
