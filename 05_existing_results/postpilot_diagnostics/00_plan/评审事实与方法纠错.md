# CRC-PHIRE：评审事实与方法纠错

本文件保留原评审中有价值的方向，纠正会影响决策的事实与推导。原评审及原先导报告不覆盖。数字来自本轮对原表的复算，见[复算结果](../04_measurement_audit/facts.json)、[脚本](../02_pipeline/measurement_audit.py)和[精确功效复算](../06_statistics_design/exact_power_correction.tsv)。

## 1. 应当接受的建议

补宿主丰度、检查近缘序列歧义、有限比较检测规则、区分患者发现与仅参考家族、探索原位provirus的相对复制覆盖，这些建议均合理。本轮已经围绕这些问题运行诊断。重点应是改善测量和生物学解释，不是保证扩量后出现多少阳性。

## 2. 项目事实与统计推导

| 原说法或容易产生的理解 | 本轮复核结论 | 对研究的影响 |
|---|---|---|
| 258份参考都可用于CRC来源菌株比较 | 258份`eligible_for_disease_comparison`均为false；196份临床标签unknown | 保留参考结构、宿主和功能用途；不强做isolate病例对照 |
| B. fragilis有142份同一物种参考 | 123份division I，另19份B. hominis／历史division II；此外93份F. animalis、23份P. micra | 分类与宿主丰度对应分别处理，不合并成单一物种 |
| 40个readsets等于40个独立样本 | 实际10名Feng供者，5 CRC＋5研究对照；40个readsets对应50个clean FASTQ文件 | 统计单位始终是供者；PE、SE和孤儿reads合并不增加样本数 |
| “全部Q为1”意味着5＋5在算术上不可能显著 | 当前342个检出检验、473个丰度检验，全局815个Q确实为1；但815项中若130项P=2/252，BH可得到约0.04976 | 当前证据不足是真实结果；不能用错误的数学不可能性论证替代 |
| 合并两个端点的BH是没有阳性的唯一原因 | 拆端点后，检出最小Q仍为1，丰度最小Q约0.93849 | 正式研究应区分检验家族，但拆家族不是“救显著性”方法 |
| 原始P＜0.05代表已发现疾病相关phage | 1项检出、19项丰度仅为名义显著，当前没有通过原全局FDR的结果 | 可探索展示效应；不能宣称已确认CRC关联 |
| 大部分是单例 | 161个vOTU零检出，236个仅1人检出，合计397/473=83.9% | 准确表述为“0或1人检出”；这是稀疏性问题，不是全部单例 |
| 1060/457说明丢掉了约2.3倍reads | 这是歧义状态与检出状态的供者×vOTU单元数之比 | 本轮另按真实fragment计数，区分独立片段和展开到多个目标的提及次数 |
| P. micra“一条read都没有” | 4个相关vOTU没有可归属覆盖，但8个单元保留了歧义片段记录 | 应区分宿主低丰度、特异序列不足、共享reads；不能直接判定不存在 |
| 923个位点都有双侧细菌宿主证据 | 923为541参考＋382宏基因组预测位点；834两侧有剩余序列，89触碰至少一端；几何侧翼不等于细菌marker | 边界、侧翼长度、宿主marker和整合可信度分别保存 |
| 双侧各≥1 kb才能开展复制覆盖分析 | 382中仅101满足该几何条件，但成熟方法可使用足够的单侧/其余宿主区域 | 不把双侧1 kb设成所有位点的硬门槛 |
| 输入mask列为空，所以原竞争参考没有mask | 实际pipeline执行了自动mask；输入空列不能代表最终生成参考状态 | 核查生成的参考、mask和manifest，不据表头猜测实现 |
| 培养分离株来源等于实验室已经有全部菌株 | `cultured_isolate_supported`只描述公开序列来源 | 关键候选选出后仍需确认实物菌株和目标元件是否保留 |
| 扩量必然得到阳性／几百个显著对象 | 当前数据不能给出这样的保证 | 扩量依据独立性、检测率、精度与重复性，不依据预定阳性数量 |
| 用细菌22.4%对2.6%的携带率计算prophage功效 | 细菌与具体prophage的检出概率不同；原功效数值也存在复算错误 | 重新用目标级检测率和合理效应范围估算；小先导只提供不确定的起点 |
| BH阈值普遍等于α×真阳性比例 | BH涉及排序后的P和拒绝数量；真阳性比例未知，观察到的显著比例也不等于它 | 删除此简化推导，不据此承诺全量发现数 |

## 3. 方法与文献解释

| 待修订理解 | 合理表述及来源 | 本项目采用方式 |
|---|---|---|
| 75%广度只适用于VLP | bulk与virome研究中均可见较高覆盖广度要求；它是操作性检测标准，不是天然真伪分界。[相关比较研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11460016/) | 保留现有0.75作为广泛序列检出的主规则，0.30仅作有限敏感性；用真实曲线与已知来源检查评价 |
| Damgaard支持直接把reads广度改为10% | 该文的组装contig匹配条件不能直接移植为read覆盖检测阈值。[原文](https://www.nature.com/articles/s43856-026-01403-1) | G—M序列对应和患者reads测量分别设规则 |
| CRC相关prophage诱导完全没人研究 | 已有colibactin触发诱导研究及相关小鼠疾病研究。[colibactin研究](https://www.nature.com/articles/s41586-022-04444-3)、[小鼠研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10578192/) | 创新定位在人群跨队列、宿主/结构证据和候选追溯，避免绝对首创表述 |
| 双峰足以把诱导升级主线；单峰说明没有价值 | 分布形状既非必要条件，也不足以排除低分母、边界或混合菌株影响 | 依据可测性、稳健性、跨队列重复和生物学问题决定支线地位 |
| PropagAtE阳性等于已证实诱导 | 工具利用病毒/宿主覆盖差异估计复制状态，不直接测切出、颗粒或感染性。[官方说明](https://github.com/AnantharamanLab/PropagAtE)、[原论文](https://journals.asm.org/doi/10.1128/msystems.00084-22) | 计算结果用于候选筛选；关键实验再回答相应机制问题，属于正常研究分工 |
| 过滤后做BH总是有效 | 过滤需与检验的零假设分布相容；不能同数据按疾病方向/P筛选后仅校正留下的对象。[独立过滤](https://pmc.ncbi.nlm.nih.gov/articles/PMC2906865/) | 正式效应分析前固定基于整体质量/可测性/检出率的过滤，并按设计核查FDR适用条件 |

## 4. 哪些是旧方案已有，哪些是本轮新增

原冻结方案§12.2已把含M_discovery成员的单元作为主家族、G-only作为补充；§12.6已将isolate疾病来源比较列为附加分析。当前先导的实现和报告没有完整展开这些层次，应称“落实和细化”，不把已有设计重新包装为全新突破。

真正新增的执行内容是：十人真实宿主谱、逐fragment歧义分解、有限检测技术校准、382个位点原始BAM配对覆盖及PropagAtE、面向正式研究的机器可读规则与下一批入口。

## 5. 本轮新增证据怎样解释

全部382个位点在本次自身组装回贴数据中达到规定的最低覆盖可评价条件。这只说明能算配对覆盖，不代表382个都拥有同等可靠的病毒身份或精确整合边界。原目录资格、宿主证据和caller边界状态仍单列。

PropagAtE首轮发现2个具有活跃复制特征的候选，来自两名对照；其中一条约70.5 kb、有双侧宿主marker且进入原合格目录，具备优先复核的价值；另一条约3.7 kb、未进入原合格目录，后续先补结构和病毒身份审阅。两条均通过当前严格比对和局部宿主分母的有限敏感性检查，为后续复制活动研究提供了实际候选。它们与CRC的关系将通过更多开发和验证队列评价。

本阶段完成了从计算筛查到具体候选的定位。后续可对重点对象开展整合结构、切出及颗粒相关实验，逐步明确其活动状态；无复制升高的对象也可因疾病关联、功能或宿主生态价值进入候选。结果表述先说明已经获得的支持，再说明下一步需要哪类证据。
