# 测量规则定稿：广泛覆盖与部分信号分开报告

日期：2026-10-08。依据为本轮实际fragment审计、4730个供者×vOTU单元重算、11个目标的有限技术校准和真实覆盖曲线。参数不按CRC差异P值选择。

## 采用什么

主终点保留**整条病毒参考序列的广泛覆盖检出，breadth≥0.75**；将breadth≥0.30作为预先定义的部分信号敏感性规则。两者测量的是不同覆盖范围，不解释成“75%是真、30%是假”。连续深度、可归属片段、歧义片段和覆盖位置全部保留。

比对和归属沿用现行保守竞争参考：identity≥95%、aligned query fraction≥90%、MAPQ≥20、baseQ≥20；primary结果与最多20个比对位置的审计结合；PE按片段覆盖并集计数。原宿主竞争背景已经做自动mask，不是把未遮蔽整株genome直接与自己的prophage竞争。

## 实际诊断说明了什么

1. 原0.75规则逐行重算与历史结果一致。其4730个单元中457个广泛检出、3213个有效测量但未达标准、551个带有不足以作阴性判断的混合归属信号、509个仅有不可归属信号。
2. 0.30规则重新计算所有状态后，检出增加到695个单元；3072个未达标准、454个混合归属不足、509个仅不可归属。新增238个单元体现覆盖较局部的可归属信号，不可直接称新增238种prophage。
3. 实际歧义fragment中，涉及病毒目标的299,032个片段约85%为病毒目标之间的歧义，约14.7%为病毒—宿主背景歧义。另有1,851,498个host-only歧义片段，不能全部算作丢失的病毒reads。
4. 技术类别预选11个不同目标，分别用SE/PE约3×已知来源模拟检验。0.75检出SE的5/11、PE的6/11；0.30在两种layout均检出11/11。近缘病毒及遮蔽后的宿主背景阴性挑战中，所选11个目标均没有被错误分配覆盖。对应条件与固定随机种子见`technical_calibration/`。
5. 这组有限校准说明：现行保守归属能够抑制所测试背景的错误归属，同时对共享区域较多的真实目标有明显敏感性代价。它支持报告部分信号、解释稀疏性，并为正式目录中的难分辨对象提出明确改进方向；尚不足以把0.30推广成全目录已验证的广泛存在标准。

## 零、NA和不同层级怎么处理

有效测量且未达阈值的结果为0，含义是“未达到本检测标准”。仅歧义或混合信号不足以作阴性判断时为NA；保留已分配的连续信号供描述。测量失败另记NA及原因。不把未达0.75的连续值自动清零，也不把NA伪装成生物学缺失。

本轮不重新试验更多全局阈值或概率分配算法。正式扩量仍以这一可解释主规则运行；只有具体对象持续不可区分时，才局部验证测量合并单元或特异区域。新测量单位必须保存到原vOTU的交叉表，并在正式效应分析前冻结。不能按哪种参数得到更多CRC显著结果选规则。

## 验收与适用范围

本轮已完成原规则复现、两规则完整状态重算、技术阳性/困难阴性检查和真实覆盖曲线恢复。技术挑战覆盖11个目标，不是全目录或所有菌株、测序平台的灵敏度/特异性估计。后续两个额外开发来源的小批技术检查用于确认可移植性；保留队列疾病效应仍不用于调参。
