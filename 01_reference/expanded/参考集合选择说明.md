# 参考集合：候选清单、下载与正式冻结

当前交付的是1,931份可下载的参考基因组候选。Jinlong按固定的accession.version下载、统一QC并核查分类后，再冻结正式集合。本次未下载新增FASTA、未做新序列ANI或系统发育分析。

执行入口是[预选详细清单](preselected.tsv)、[下载清单](download_manifest.tsv)和[accession文本](download_accessions.txt)；三者的候选accession及顺序一致。历史参考见[旧258清单](../reference258_manifest.tsv)和[逐份对账表](old258_reconciliation.tsv)。

## 怎样选的，为什么不是每种相同株数

先按文献/宿主生态定义36个检索单元，覆盖反复CRC富集、对照关联/耗竭、新分类和方向不确定的背景。公共数量少的物种尽量保留合适记录；资源多的物种按明确预算、BioProject/地区/体位/当前种标签分层轮转，层内优先人肠道、其他人来源及组装质量，类型锚点先保留。预算不是功效计算，地区记录也可能是提交机构而非真正采样地，正式推断不能机械使用。

E. coli只盘点完整RefSeq的有界结构背景，未穷尽全部E. coli。所有查询排除NCBI标识的MAG；未知或错误标签仍可能存在，Jinlong须检查培养分离来源。公共MAG如UHGG可另作宿主辅助，不能混入培养株数。

## 质量规则的实际含义

常规metadata起点为报告完整度≥90%、污染≤5%、≤200 contigs。201–500 contigs备用，>500不入主预选；公共指标缺失仍可条件预选，不能当已通过。旧CheckM估计异常通常进待查；完整组装或类型株中的有限结构锚点（至少70%完整、至多15%污染、≤200 contigs）可条件保留并强制重查，此次81份。这个例外只是避免公开旧指标机械删去整个结构谱系，**不是把70%/15%改成正式QC门槛**；实际污染需剔除/修复，不能因类型株身份放行。参见[CheckM2方法](https://pubmed.ncbi.nlm.nih.gov/37500759/)。

显式分类冲突待查，NCBI Inconclusive只表示其检查不能定论，不自动剔除所有稀有物种。旧名、submitted_species和最终ANI分类需分开；Fusobacterium和Faecalibacterium尤其如此。suppressed RefSeq不得直接优选；若存在current配对GenBank则使用current并保留对应记录。[NCBI状态说明](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/data-processing/policies-annotation/genome-processing/version-status/)

## 疾病和宿主标签

本集合并非CRC病例组与健康对照组。大多数公开分离株无可靠疾病标签，unknown保留unknown；口腔不是健康对照，粪便不是健康，肿瘤来源也不自动可与其他研究来源比较。表中的疾病方向来自文献层宿主背景，不是每份genome的临床标签。所有当前候选的菌株疾病比较资格暂为false，待有足够可比metadata后再判定。

## 下载、QC与冻结

在含有`download_accessions.txt`的目录中，用NCBI官方Datasets工具执行以下模板，并记录实际工具版本：

```bash
datasets download genome accession --inputfile download_accessions.txt --include genome --dehydrated --filename reference_candidates.zip
unzip reference_candidates.zip -d reference_candidates
datasets rehydrate --directory reference_candidates
```

逐accession的下载命令也在[下载清单](download_manifest.tsv)中。工作目录、并行、缓存和重试由Jinlong按执行环境确定；命令依据见[NCBI Datasets下载文档](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/reference-docs/command-line/datasets/download/genome/)。按固定版本下载，所需版本不可用时记录失败与替换决定，不能静默改成latest。下载失败单列，不能计为QC排除或菌株不存在。

逐文件保存下载状态、实际字节数、官方校验文件及本地SHA256。目前候选表中的官方MD5和大小尚未逐FASTA取回，相关占位字段不表示文件已验证。

下载后统一核查完整度、污染、contig/N50、分类、同株别名及明显重复；固定实际使用的NCBI/GTDB版本、ANI方法、QC工具和数据库版本。记录短读碎片化对prophage调用的影响，并重查条件保留的结构锚点及公共质量指标缺失的记录。正式主要参考建议优先使用完整度≥90%、污染≤5%的组装，最终工具、阈值组合和例外由Jinlong明确记录。

为每条候选填写`final_included`、`excluded`、`replaced`或`review`及理由。正式冻结表至少包含参考ID、taxon、strain/别名、accession.version、BioSample/Project、实际来源、分类版本、QC工具/库版本、完整度/污染/碎片化、FASTA路径别名、SHA256、参考角色和纳排/替换理由。最终种数、独立菌株数和genome数分别从冻结表计算。
